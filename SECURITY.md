# Security Policy

This repository contains security guidance and may contain intentionally insecure examples for educational comparison.

## Reporting a problem

Report issues when a pattern, example, test, or recommendation could lead engineers to implement an insecure design.

Examples include:

- an insecure example that is not clearly labeled;
- a bypass of a recommended control;
- leaked or real credentials in example content;
- unsafe dependency or configuration advice;
- incorrect claims about prompt-injection prevention;
- stale guidance that became unsafe after an upstream change.

Do not include production secrets, private customer data, or exploit details from non-public internal systems in a public issue.

## Example-code disclaimer

Reference implementations demonstrate security properties; they are not automatically production-ready. Production use requires environment-specific threat modeling, authorization design, observability, error handling, availability, privacy, and operational review.
